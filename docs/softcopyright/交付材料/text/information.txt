软件名称：面向越南留学生的铁道专业汉越术语翻译学习软件V1.0
版本号：V1.0
开发的硬件环境：Linux 本地开发服务器或普通 PC 工作站，建议 4 核 CPU、16GB 内存、固态硬盘，能够同时运行 Node.js、MySQL、Chromium 和 PDF 导出工具。
运行的硬件环境：Linux/Windows 应用服务器或教学管理终端，建议 2 核 CPU、4GB 内存、20GB 可用磁盘空间；用户通过浏览器或 H5 页面访问。
开发该软件的操作系统：Linux
软件开发环境 / 开发工具：Node.js、npm、Express、Vue/Vite 或静态 H5、MySQL、Chromium、命令行终端、Git。
该软件的运行平台 / 操作系统：浏览器 Web/H5 应用，后端运行于 Node.js，数据库运行于 MySQL。
软件运行支撑环境 / 支持软件：Node.js、MySQL、现代浏览器、静态资源服务、JSON API 服务。
编程语言：JavaScript、Vue、HTML、CSS、SQL、Node.js 脚本。
源程序量：本次源码稿选入 27 个真实源码、配置、SQL 或脚本文件，不包含第三方依赖、构建产物、截图和 PDF。
开发目的：随着中国—东盟全面战略伙伴关系持续深化，中越双边基建合作、铁路互联互通项目落地提速，跨境铁路建设、运维、人才交流合作日益频繁，铁道领域国际化人才缺口持续扩大。依托“一带一路”教育合作、中国—东盟职教共同体建设政策红利，国内各大高校持续扩招越南铁道专业来华留学生，越来越多越南学子来华学习轨道交通、铁道工程、铁路运维等核心专业，助力中越铁路经贸与基建协同发展。当前，越南铁道留学生在专业学习中面临显著的语言与专业适配难题。铁道行业术语专业性强、精准度要求高、专有词汇量大，通用翻译软件存在术语翻译不规范、行业释义缺失、汉越对照不贴合铁道场景等问题。同时，目前缺乏针对性的铁道专业汉越术语学习工具，留学生课堂听课、教材研读、实验实操、毕业设计及后续跨境就业对接时，常因术语理解偏差、双语转换不熟练出现学习障碍，极大影响专业学习效率与人才培养质量。为适配中越铁道领域人才交流需求，解决越南留学生专业术语学习痛点，搭建专业化、场景化的双语术语学习体系，助力留学生快速掌握铁道专业核心词汇，夯实专业基础，同时为中越铁路领域技术交流、人才互通提供基础支撑，因此开发本铁道专业汉越术语翻译学习软件极具现实必要性与应用价值。
面向行业 / 领域：教育信息化、国际留学生服务、在线学习与教学管理。
软件的主要功能：认证与权限模块面向管理员、教师、学生，提供统一登录、令牌签发、角色判断和密码修改，主要通过/api/auth/*实现，并围绕sys_user、sys_role、sys_login_log等数据对象完成业务处理。术语分类模块面向管理员、教师、学生，提供术语分类查询、新增、编辑和删除，主要通过/api/terms/categories实现，并围绕term_category等数据对象完成业务处理。铁道术语模块面向管理员、教师、学生，提供汉越英术语查询、分页、检索、收藏、新增和编辑，主要通过/api/terms实现，并围绕railway_term、favorite_term等数据对象完成业务处理。练习测评模块面向学生，提供选择题、判断题、填空题、翻译题出题和提交判分，主要通过/api/practice/*实现，并围绕practice_record、practice_answer等数据对象完成业务处理。学习分析模块面向学生、管理员，提供练习统计、正确率、分类趋势、错题统计和管理端汇总，主要通过/api/analysis/*实现，并围绕practice_record、wrong_question等数据对象完成业务处理。系统管理模块面向管理员、教师，提供用户、角色、登录日志和操作日志查询管理，主要通过/api/system/*实现，并围绕sys_user、sys_role、sys_login_log、sys_operation_log等数据对象完成业务处理。系统支持用户在真实运行页面中完成登录、查看、查询、提交、统计或管理操作，并通过后台接口和数据库实现数据保存、权限限制、业务结果返回和运行检查。本次软著材料重新采集了 H5 竖屏校准截图和桌面管理截图，能够证明页面真实可运行、业务数据真实加载、核心流程可交互。
软件的技术特点：系统采用浏览器前端、Node.js/Express 后端和 MySQL 数据库的分层结构，前端负责页面渲染、语言切换、表单交互和请求发起，后端负责认证鉴权、角色控制、业务接口、数据查询和异常处理，数据库保存用户、角色、业务主数据、记录数据和统计数据。系统支持本机 Linux 环境部署，截图和 PDF 导出阶段通过本机回环地址访问本地服务，敏感配置在文档和源码稿中统一脱敏。
