软件名称：面向越南留学生的铁道专业汉越术语翻译学习软件
版本号：V1.0

开发的硬件环境：通用 x86_64 架构个人计算机或服务器，建议 CPU 双核及以上、内存 8GB 及以上、可用磁盘空间 20GB 及以上，支持运行 Node.js、浏览器和 MySQL 数据库服务。

运行的硬件环境：通用 PC、教学机房电脑、教师办公电脑、学生个人电脑、平板或手机浏览器终端均可访问。后端服务部署在支持 Node.js 和 MySQL 的服务器或本地教学服务器上，前端通过浏览器访问。

开发该软件的操作系统：Linux 桌面/服务器环境，可兼容 Windows、macOS 等常见开发环境。

软件开发环境 / 开发工具：Node.js、npm、Vite、Vue3、Express、MySQL、Chromium 浏览器、代码编辑器和命令行工具。

该软件的运行平台 / 操作系统：前端运行于支持 HTML5、CSS3 和 JavaScript 的现代浏览器；后端运行于支持 Node.js 的 Linux、Windows 或 macOS 操作系统；数据库运行于 MySQL 环境。

软件运行支撑环境 / 支持软件：Node.js 运行时、MySQL 数据库、现代浏览器、npm 包管理工具。系统前端通过 H5 页面访问，后端通过 REST API 提供认证、术语管理、练习、分析和系统管理服务。

编程语言：JavaScript、Vue 单文件组件、HTML、CSS、SQL。

源程序量：约 2500 行自研源码，包含前端页面逻辑、样式、国际化资源、接口封装、后端路由、鉴权中间件、数据库初始化、分页工具、测试数据脚本和接口冒烟测试脚本。

开发目的：本软件面向在华学习铁道相关专业的越南留学生，解决学生在铁道专业中文术语理解、汉越互译、专业词汇记忆和练习反馈方面的学习需求。系统通过三语言界面、结构化术语库、多题型练习和学习数据分析，帮助学生逐步掌握铁路基础设施、轨道工程、机车车辆、信号通信和调度指挥等领域的专业术语，同时为教师提供统一的术语内容维护和学习情况查看工具。

面向行业 / 领域：教育信息化、职业教育、留学生教学、铁道工程与轨道交通专业术语学习。

软件的主要功能：系统提供统一登录认证功能，支持管理员、教师和学生通过账号密码进入系统，并根据角色展示不同功能范围；提供中文、英文、越南语三语言界面切换功能，帮助越南留学生在熟悉语言环境中学习铁道专业中文术语；提供专业术语管理台，教师和管理员可以维护术语分类、中文术语、英文翻译、越南语翻译、拼音、难度、释义、例句和启用状态，并可通过关键词、分类、难度和分页方式查询术语；提供 H5 练习平台，学生可以按题型、分类、难度和题目数量生成单选题、判断题、填空题和翻译题，提交后系统自动判分并展示结果；提供错题本功能，将学生答错的术语记录下来并统计错误次数，便于后续复习；提供学习数据分析功能，统计练习次数、答题数量、正确数量、平均得分、正确率、学习趋势和分类掌握情况；提供后台系统管理功能，支持用户列表、角色列表、登录日志和操作日志查询，并通过分页方式处理百条以上数据；提供数据库自动初始化和测试数据准备能力，保证系统在本地教学和演示环境中可以快速部署、验证和交付。

软件的技术特点：系统采用 H5 前端、Node.js 后端和 MySQL 数据库的前后端分离架构。前端使用 Vue3 和 Vite 构建响应式页面，能够同时适配移动端竖屏学习场景和后台横屏管理场景；后端使用 Express 提供 REST API，并通过 JWT 鉴权保护业务接口；数据库采用 utf8mb4 字符集，支持中文、英文和越南语多语言字段存储；术语、用户、日志、练习记录和错题等列表接口统一支持分页返回，返回结构包含数据行、总数、页码和每页数量；系统内置数据库初始化、测试数据生成和接口冒烟测试脚本，便于部署、测试和验收；敏感配置通过环境变量提供，文档和源码稿中统一脱敏处理。
